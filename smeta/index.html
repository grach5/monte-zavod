Три ситуации и что делать в каждой

Точное совпадение

Код описывает ровно наше изделие

В базе есть позиция с тем же типоразмером и классом бетона — например, камень бортовой БР 100.30.15 в бетоне В30. Берите код как есть, единица измерения совпадает с нашей отгрузочной.

Обобщённая позиция

В базе есть только группа по марке или толщине

Так устроены стеновые камни: они идут по марке прочности в кубометрах, без деления по размерам. В этом случае в таблице дан габаритный объём изделия — по нему штуки переводятся в кубометры.

Позиции нет

Изделия нет в классификаторе

Так с вентиляционными камнями и облицовочным кирпичом. Позиция вносится по прайсу производителя с приложением коммерческого предложения — счёт, характеристики и документы на партию мы предоставляем.

Про марки бетона у стеновых камней. В базе две параллельные группы: 05.2.03.01 — камни из лёгкого бетона, 05.2.03.02 — из тяжёлого. Какая из них верна, определяет не размер изделия, а вид бетона по паспорту партии. В таблице по умолчанию указана группа лёгкого бетона, альтернатива — в карточке каждой позиции. Если для сметы нужна однозначность, запросите паспорт: в нём вид бетона указан прямо.
